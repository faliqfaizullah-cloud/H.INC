# H.INC
Health platform in one system: single dashboard, simple setup flow, sensor-scan flow.
All numbers come from what the user logs (stored on-device). Glucose stats per day: average, time in range (70-140 mg/dL), variability (coefficient of variation), spikes (share of readings that jump 30+ mg/dL above the previous one).
Build: push -> Actions -> "Build APK" -> APK artifact + a GitHub Release is created automatically.
