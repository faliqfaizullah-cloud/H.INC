# H.INC
Health platform restructured into one scalable system: a single dashboard (Sugar, Average Glucose, Time in range, Variability, Vitamin D, Spikes), a simplified reminder/setup flow, and a sensor-scan flow — less screen switching, faster data access.

Build: push to GitHub → Actions → "Build APK" → download `H.INC-debug-apk`.
Local: `gradle assembleDebug` (Gradle 8.7, JDK 17).
